# Finish the Story Through a Clear PR

## What changed
The Story workflow now opens one final pull request after checked Tasks and Story validation finish.

## Why it matters
Reviewers can decide on the completed change in one place, without a second final approval.

## Verification
- Local build and focused template tests passed.
- Story-wide verification passed.
- Hosted CI is pending; it has not been counted as passing.

## Known risks and limits
These template checks confirm written instructions, not live agent behavior or pull-request hosting. A separate isolated integration evaluation has not been authorized.
