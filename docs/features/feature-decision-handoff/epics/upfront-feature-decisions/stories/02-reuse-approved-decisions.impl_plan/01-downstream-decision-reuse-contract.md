# Step: Carry and verify scoped Feature Decisions at downstream gates

## Goal

Align planned-feature planner, executor, and eval-authoring guidance so each owning gate verifies its governing SDD record and reuses an unchanged approval without re-asking, while stopping only work affected by an absent or changed decision.
